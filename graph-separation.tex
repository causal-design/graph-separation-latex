\noindent Version 3.0.0-rc.1 (review candidate, 28 October 2026).

Download \texttt{graph-separation.sty} and put it beside your \texttt{.tex} file.
Add this line to the preamble:
\begin{verbatim}
\usepackage{graph-separation}
\end{verbatim}
The source and reproducible build workflow are maintained at:\\
\url{https://github.com/qingyuanzhao/graph-separation}.

The package requires \texttt{amsmath}, \texttt{amssymb}, \texttt{tikz},
\texttt{adjustbox} and \texttt{centernot}, supplied by standard TeX distributions.

The squiggly relations use the actual AMS font glyphs. One-ended and unheaded
squiggles follow \verb|\rightsquigarrow|; two-ended squiggles follow
\verb|\leftrightsquigarrow|. At 10\,pt these have respective TeX widths
10\,pt and approximately 13.9\,pt. Script styles use the font's smaller optical
designs. Half-arrowhead orientation and all existing command names are retained.
Straight relations retain the published website/course design (v2.0).

\noindent The higher-level commands describe edges, walks, arcs and connections.
An asterisk combines pieces of a walk; the labels \(\mathrm{d}\) and
\(\mathrm{t}\) distinguish d-connection and treks. In particular,
\verb|\mconnarc| has no superscript \(\mathrm{m}\).
